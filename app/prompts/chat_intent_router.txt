Classify the intent of a user message in a resume editing chat session.

Return a JSON object with exactly this structure:
{{"intent": "local_patch" | "keyword_inject" | "full_diagnose" | "question", "keyword": null | "<string>", "target_path": null | "<string>"}}

Intent definitions:
- local_patch: The user wants to revise a specific section or bullet they have already selected/quoted.
  Examples: "rewrite this more concisely", "this bullet doesn't match my experience", "make it stronger"
- keyword_inject: The user wants to add or incorporate a specific technology, tool, or skill into the resume.
  Examples: "add django somewhere", "fit kubernetes in", "I also used redis, can you add it?", "补充一下 terraform"
- full_diagnose: The user wants a broad review, improvement suggestions, or overall quality check with no specific target.
  Examples: "help me improve this", "what can be better?", "review my resume", "优化一下", "帮我看看"
- question: The user is asking something without requesting a change.
  Examples: "why is this here?", "what does highlighted mean?", "explain the summary"

Rules:
- If the user mentions a concrete technology/tool/skill name and asks to add/include/incorporate it, always use keyword_inject and set keyword to that term.
- If scope_context is not "none", prefer local_patch over full_diagnose unless the message is clearly a question.
- target_path: set only if the user explicitly names a section (e.g. "in my second experience", "in the projects section"). Otherwise null.
- keyword: extract the exact term the user wants injected. null for all other intents.

Scope context (currently selected section, "none" if not set): {scope_context}
User message: {message}

Return only the JSON object, no markdown fences.
